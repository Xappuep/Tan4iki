# Стальные рубежи

Локальная браузерная 8-bit танковая аркада. Игрок защищает штаб и уничтожает вражеские машины на одном квадратном рубеже.

Игра оригинальная: визуал рисуется программно, звуки генерируются в браузере, сторонние ассеты и сервер не используются.

## Как запустить

1. Откройте файл `index.html` в современном браузере (Chrome, Edge, Firefox).
2. Нажмите **Начать игру**.
3. Для мобильного экрана используйте экранные кнопки внизу.

Сервер не нужен. Если браузер ограничит `file://`, откройте папку через любой локальный просмотрщик файлов — скрипты подключены без ES-модулей.

## Управление

- **WASD** или **стрелки** — движение
- **Пробел** — выстрел
- На телефоне — крестовина и кнопка «ОГОНЬ»

## Цель

Уничтожьте все вражеские танки уровня, не потеряв штаб и все жизни.

## Объекты

- Кирпич — разрушается выстрелом
- Сталь — обычный снаряд не берёт, усиленный берёт
- Вода — непроходима
- Лес — маскирует технику
- Лёд — ускоряет движение
- Бонусы: усиленный выстрел, щит, дополнительная жизнь
